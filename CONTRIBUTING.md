# Contributing

Thank you for contributing to this beginner-friendly bioinformatics project.

## Before opening an issue

- Use the provided issue templates in `.github/ISSUE_TEMPLATE/`.
- Include clear reproduction steps for bugs.
- Add relevant labels when possible to help triage.

## Before opening a pull request

- Keep changes focused and educational.
- Update documentation when notebook behavior or setup changes.
- Ensure notebook cells run in order from top to bottom.
- Avoid committing large generated outputs unless they are intentionally part of learning content.

## Notebook contributions

- Preserve beginner-friendly explanations and biologically meaningful variable names.
- Prefer simple, readable examples over advanced optimizations.
- Document any dependency changes in `requirements.txt` and `README.md`.
